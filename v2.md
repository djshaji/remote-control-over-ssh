# v2 implementation summary

1. **SSH verification and error handling**
   - Replaced permissive SSH host verification with fingerprint-based verification in `SshManager`.
   - Added required SSH fingerprint support to `SshProfile` and the SSH profile form.
   - Introduced structured `SshResult` responses and surfaced connection/command errors in the dashboard UI instead of relying on `printStackTrace()`.

2. **Room migration safety**
   - Removed `fallbackToDestructiveMigration()` from `AppDatabase`.
   - Bumped the database to version `3` and added an explicit migration for the new `hostKeyFingerprint` column.
   - Enabled Room schema export under `app/schemas/`.

3. **Atomic remote-profile saves**
   - Added an `AppRepository` layer backed by `RoomAppRepository`.
   - Moved remote-profile persistence into a Room transaction.
   - Cleared old command rows on save and skipped blank command strings during persistence.

4. **Input validation**
   - Added reusable validation helpers for SSH profiles and remote profiles.
   - Updated both add dialogs to show inline validation errors instead of silently accepting invalid values.
   - SSH profile creation now requires profile name, host, port, username, private key, and host fingerprint.

5. **Repository and dependency injection refactor**
   - Added `AppContainer` to `RemoteControlApplication`.
   - Updated `MainActivity` to construct ViewModels from injected repository/SSH dependencies.
   - Removed direct Room construction from ViewModels and injected an `SshClient` into `DashboardViewModel`.

6. **Behavior-focused tests**
   - Replaced placeholder tests with validation, slider-command, dashboard debounce, and Room relationship tests.
   - Added fake repository / fake SSH client coverage for `DashboardViewModel`.
   - Added instrumented database tests for cascade and foreign-key behavior.

7. **Maintenance cleanup**
   - Removed the duplicate `INTERNET` permission from `AndroidManifest.xml`.
   - Removed currently unused dependencies from `app/build.gradle.kts` while keeping required ones such as Material and Navigation serialization support.
